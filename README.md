# SwiftCRM (web)

The compiled web version of SwiftCRM: Swift compiled to WebAssembly, running entirely in your browser.

- **Chrome or Edge:** choose the shared Proposals folder; SwiftCRM keeps `crm.db` in its `SwiftCRM` subfolder.
  Existing files in the folder are only read.
- **Other browsers:** the library stays in the browser; use **Open crm.db** and **Save crm.db**.

Nothing is uploaded: the app talks to no server (PDF text is read with pdf.js loaded from cdnjs).

This repository holds only the built files; the sources are private.
